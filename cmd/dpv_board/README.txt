===================================================

ЗАЧЕМ. С бортовыми параметрами полётника в симе (ATC_ANGLE_MAX 20, ATC_INPUT_TC 0.3 — 0798ac0)
наклон отвечает τ 0.45 с + запаздывание 0.24 с вместо 0.26 с старого сима (снято по полёту
rollbig_rc_nogust_20260930_173309, R² 1.00). Штатный DpVins (dpvins/brake5_stop) на такой модели
у края: на VinsHold крен почти не отзывался, боковая ось качалась. Стенд src/lab/dpvins_axis_stand.py
(штатный объект, модель борта): запаздывание ×1.3 роняет отклик стика втрое и раскачивает висение.

ЧТО МЕНЯЕТ. Один профиль dpvins/: brake5_stop → board1 (KI 8→3, VSMOOTH 0.3→0, FF 10→30; kp не
трогаем). Канал — углы (mission/att_out_replay), остальное = cmd/att_out att.

КАК ЛЕТАТЬ.
  bash cmd/dpv_board/dpv_board.sh <base|board> [gust|nogust]      # по умолчанию roll_big.json
  BS_REPLAY_SCENARIO=/lab/joystick/scenarios/vinshold_ring.json bash cmd/dpv_board/dpv_board.sh board

на ярусе 1, медиана |v бок| при стике в центре, паузы после движений; на vinshold_ring — тангаж и
качание после отпускания.
