cmd/5 — A/B-полёт DpVins brake5_tail + по-осевая защёлка трима (latch_axis)
==========================================================================

Зачем создан
------------
cmd/4 (brake5_tail: brake 5, кап 2, хвост брейка как у демпфера, ki 8) висение прошёл:
lv2_joy_20260906_112232 — пик 2.36 / остаток 0.32 / vmax 1.44 против 4.6–5.5 у cmd/3.
Полёт в движении lv2_joy_20260906_113224 (крейсер стиком тангажа, ветер сбоку) вскрыл:
на живом стике трим DpVins не учится ВООБЩЕ — стрелка ветра стоит. У DpHold учится.
Причина в коде vins_axes.py: `frozen = stick or …`, где `stick` истинен при отклонении
ЛЮБОГО из двух стиков, — трим морозится по ОБЕИМ осям; `sat` (анти-виндап) тоже ИЛИ.
У демпфера защёлка _TRIM_LATCH ПО-ОСЕВАЯ: каждый _FlowDamper1D морозит только СВОЙ
И-член, свободная ось (крен при стике тангажа) держит линию и учит трим дальше.

Цена по истине Gazebo (боковая скорость тела на плечах стика ≥ 3 с, полёт 113224):
  ярус    плечо   vfwd   vlat_mean  снос,м   трим
  DpHold  22.9 с  1.13   0.16        3.6     учится
  DpVins  16.2 с  1.16   0.76       12.3     стоит (4,−11)
  DpVins  10.4 с  1.57   0.58        6.1     стоит на ВЕРНОМ триме висения (−27,57)
  DpVins  27.7 с  0.40   0.56       15.5     |трим| 25 стоит, вращается с курсом
Даже с верным тримом висения крейсер сносит 0.58 м/с: боковая сила ветра на ходу
больше, чем в висении (лобовое ∝ |v_возд|·v_возд — ~×1.9 при 1.6 м/с вперёд и 1 сбоку),
её надо доучивать на ходу; P-канал kp 32 держит остаток 1 м/с на каждые 32 PWM.
У демпфера kp 90 + учёба свободной оси → 0.16 м/с.

Что меняет
----------
Код (этот коммит): DpVins.latch_axis (BS_DPVINS_LATCH_AXIS, дефолт 0 = старое):
на живом стике морозится только компонента трима вдоль ДВИЖИМОЙ оси (и её хвост
до гвоздя после отпускания), свободная ось учится рабочим ki (не ki_trim: гвоздя на
стике не будет, фаза быстрого захвата не кончалась бы); sat — по осям; замороженная
ось в мир не крутится (её компонента ошибки = 0). Движимую ось не учим: выучила бы
«ветер + лобовое крейсера», после стопа рывок (та же причина у защёлки демпфера).
Тест test_dpvins §23 (старое/новое, оба стика, хвост до гвоздя).
Профиль dpvins/brake5_axis.txt против brake5_tail.txt: только BS_DPVINS_LATCH_AXIS=1.
Висение без стика — идентично cmd/4 (стенд 2.44/0.04).

Как летать
----------
  bash cmd/5/5.sh
Как 113224: взлёт с CH6 в центре, висение на DpVins до трима (стрелка ветра встала,
~10–20 с), затем плечи стиком ТАНГАЖА 10–30 с с ветром СБОКУ (курс поперёк 98°),
в обе стороны, стоп на 5–10 с между плечами, повтор; CH6 вверх — контроль DpHold
в том же полёте; посадка. Смотреть стрелку ветра на ходу: теперь она должна ЖИТЬ.
Каталог: docker/sim/output/joystick/cmd_5/.

Чем судить
----------
Сегменты стика ≥ 3 с, боковая скорость тела по истине Gazebo — src/lab/stick_lateral.py:
  docker exec p1317_nav bash -lc "source /opt/ros/humble/setup.bash; \
    source /root/sim_ws/install/setup.bash; \
    python3 /lab/stick_lateral.py /root/sim_ws/output/joystick/cmd_5/<RUN> [--min-seg 3]"
плюс висение — gust_hold_compare.py как в cmd/4. Критерии:
  успех — vlat_mean ≤ 0.3 м/с на плечах ≥ 10 с (было 0.56–0.76), wnr на ходу меняется,
          после отпускания |v| гаснет монотонно (нет рывка), без бокового качания;
          висение под порывами не хуже cmd/4 (pk ≤ 3, rs ≤ 0.5);
  провал — снос как был (≥ 0.5) → смотреть sat/знак интеграла; рывок после стопа →
          хвост защёлки движимой оси; боковое качание T 5–10 с → ki 6.

Результат
---------
ПРОШЁЛ (2026-09-06, со слов пилота «работает»; bag не разбирался — в joystick/ на момент
записи прогона cmd_5 нет). Следующее по списку cmd/3 — (в) фаза BRAKE в статусе:

дальше разбор порывов по фазе, а не по косвенным признакам.

Полёт с полем фазы lv2_joy_20260906_130326 (тот же кандидат brake5_axis; висение 2.6 м,
ветер слева; разбор src/lab/brake_phase.py + gust_hold_compare):

  DpHold   2      2.02     0.37     0.91   1.8 с   (в порыве BRAKE 0.7–1.0 с, дальше HOLD с тримом до 80)

Относительно ГВОЗДЯ (проекция на ось ветра, + по ветру), установившийся цикл DpVins:
  фронт: −0.8 м (против ветра, остаток перелёта) → порыв гонит К гвоздю, фаза не away,
  тормоза нет, разгон до 1.2 м/с → BRAKE за гвоздём (+3.5 с, e +0.6) → стоп на +2.2 (+5.5 с)
  → HOLD, трим учит порыв 14 → 65 → спад порыва (+11 с) e +0.6 → трим-излишек гонит назад

  гвоздя 1.5–1.8, на фронте 0.06–0.5 (возврат в точку), перелёт тоже есть (1.5 @+14 с).
  Трим в BRAKE учится (ifz=1 — 1 кадр из 99, анти-виндап), как задумано brake_t −1.
Первый цикл DpVins 7.99 м — ДЫРА ВХОДА: ярус 1 включился в 89.2 без гвоздя (set/set:
гвоздь только по стопу ПОСЛЕ движения, _moved), порыв в 90.0 → 11 с дрейфа на P без
тормоза (−7.9 м от будущего гвоздя), гвоздь взят лишь по стопу в 100.1. Посев трима
работал (10 → 70 за дрейф), но станции не было.
Дальше: (а) гвоздь сразу на входе, если трим посеян (armed) и борт стоит — _moved нужен
был только фазе ki_trim; (б) тормоз «к гвоздю» / авторитет: разгон 1.2 м/с через гвоздь и
возврат 1.2 м/с на тримe-излишке — оба от kp 32 (DpHold 0.7 при kp 90); twist для kp.
