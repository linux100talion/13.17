Замечание пилота: «хотелось бы больше скорости/доверия стикам; DpVins хуже держит курс».
1) СКОРОСТЬ: цель DpVins при полном стике = c_fwd·cmd_gain = 0.99·4 = 4.0 м/с, достигается
   63–93 %. Движимая ось — чистый P (kp_fwd 40; трим на стике заморожен, иначе рывок после
   стопа): установившаяся ошибка = (лобовое + ветер)/kp ≈ 30–40 PWM-экв. / 40 = 0.75–1 м/с.
   У DpHold цель 5 единиц канала при kp 90 — ошибка втрое меньше.
2) КУРС (линия): средний боковой снос мал у обоих (0.0–0.35 против 0.05), но RMS 0.7–0.97
   против 0.49 — под порывами DpVins гуляет поперёк плеча ±1 м/с, DpHold ±0.5; худшее плечо
   ушло на 7.5 м. Не «доверие стикам», а СТРУКТУРА свободной оси: у DpHold она держит ЛИНИЮ
   (гвоздь остаётся, BRAKE, kp 90); у DpVins стик снимал 2D-гвоздь, свободная ось держала
   только скорость 0 на P kp 32 (порыв 75 PWM-экв. → 2.3 м/с) + трим ki 8 (3.7 PWM/с — за
   плечо 22 с не успевает). Рыскание держится одинаково (DpYawHold общий): 1.4–3° за плечо.

Что меняет
----------
Код (этот коммит, vins_axes.py):
- DpVins.ff (BS_DPVINS_FF, дефолт 0): прямая передача стика — к выходу добавляется −ff·цель
  стика (PWM на м/с цели), знак как у P при v < цели; только на стик-цели, станция висения
  не тронута. Зеркало BS_YAW_PILOT_GAIN рыскания: стик = наклон, контур только правит.
- DpVins.line_hold (BS_DPVINS_LINE_HOLD, дефолт 0): при стике ОДНОЙ оси 2D-гвоздь остаётся,
  свободная ось держит проекцию гвоздя на себя в текущем курсе (линия через гвоздь вдоль
  курса, как StationFrame демпфера) законом станции (RETURN/BRAKE); уход курса > 17° —
  перезахват линии в текущей точке; после отпускания гвоздь снимается — заново по стопу.
  Тест test_dpvins §25–26.
Профиль dpvins/brake5_line.txt против brake5_pin.txt: CMD_GAIN 4 → 5, FF 0 → 10, LINE_HOLD 0 → 1.
kp НЕ трогаем (следующий шаг после этого полёта). Висение — идентично cmd/6.

Как летать
----------
  bash cmd/7/7.sh
Как 150448: взлёт, висение на DpVins до трима, плечи стиком тангажа В УПОР по 15–25 с в обе
стороны с ветром сбоку (сквозь порывы), стопы между плечами (смотреть рывок при отпускании),
одно-два плеча на DpHold для сравнения, посадка. Каталог docker/sim/output/joystick/cmd_7/.
На HUD: brk= на плече должно быть rel/hold или rel/brk (движимая ось rel, свободная держит).

----------
  stick_lateral.py <RUN>      — vfwd ≥ 4.5 м/с при |rcp| ≈ 395 (было 2.5–3.7; DpHold 4.2),
                                vlat_rms ≤ 0.5 (было 0.7–0.97), снос за плечо ≤ 1 м (было до 7.5)
  brake_phase.py --no-trans   — на плече фазы rel/hold|brk; после стопа гвоздь по стопу,
                                |v| гаснет монотонно (нет рывка от исчезнувшего ff)
  gust_hold_compare.py        — висение как cmd/6 (pk ≤ 3, rs ≤ 0.5, vmax ≤ 1.5)
Провал: рывок при отпускании → BS_DPVINS_FF 5; перелёт цели (v > цели на 0.5) → ff 5;
качание поперёк плеча → kp_lat выше / brake на линии.

Результат
---------
ПРОШЁЛ по скорости и линии (lv2_joy_20260906_160730, «стало заметно лучше»):
  плечи стиком в упор (stick_lateral.py, плечи ≥ 10 с):
    DpVins 4.22 / 4.35 / 4.59 м/с (было 2.5–3.7; цель 5.0 — 84–92 %), vlat_rms 0.49–0.72
    (было 0.70–0.97), снос за плечо 0.8–3.1 м (было до 7.5)
    DpHold 3.96 / 4.13 м/с, vlat_rms 0.43–0.56, снос 2.3–4.4 м
  → полный стик у DpVins быстрее DpHold, линия на уровне DpHold.
НО при отпускании стика на ходу DpVins плывёт (release_stop.py): до гвоздя 5–12 с и 7–16 м с
5 м/с против 1.5–2.4 с и 3–5 м у DpHold; на виражах гвоздь не брался 8–11 с. Причина —
цель 0 на чистом P без гвоздя (τ 2.5 с при kp 40), порог 0.3 под ветром не достигается,
таймаута нет. → cmd/8: settle_brake (−brake·v без точки) + pin_t 3.
