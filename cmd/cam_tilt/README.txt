cmd/cam_tilt — A/B НАКЛОНА КАМЕРЫ ВНИЗ для канала вида сверху (2026-10-03)
=========================================================================

Зачем
-----
После калибровки Kalibr камера борта — 59° по горизонтали (fx 1124.7), стоит горизонтально. Землю
канал вида сверху видит только нижним краем кадра: ближайшая земля 3.1·h впереди, взгляд 17°→13°.
Ошибка канала ∝ h/sin²α (стенд ipm_band_ab, память ipm-band-width) — против 90°-камеры ≈2.3× хуже;
прогон ipm59 (cmd/ipm_lever/README.txt) показал бок. ошибку ×1.5–2. Рычаг — не размер полосы, а угол
взгляда: наклонить камеру вниз. Цена — меньше горизонта для VINS/NN1 и переделка крепления на борту.

Что меняется
------------
Только extrinsicRotation камеры (копия бортового config.yaml с осью Z, опущенной на θ; генерирует
cam_tilt.sh в docker/sim/output/cam_tilt/, отдаёт через CAM_CFG). Из неё — поза camera_link в
Gazebo, VINS сима, наклон демпфера. Профили, сценарий, ветер — cmd/ipm_lever wl + world/baseline (5 м/с).

Как летать
----------
    bash cmd/cam_tilt/cam_tilt.sh 15
    bash cmd/cam_tilt/cam_tilt.sh 25
Контроль 0° — ipm59_wl_baseline_20261003_194301 (те же условия).

Чем судить
----------
src/lab/ipm_lever_ab.py по прогонам (бок. ошибка канала против истины по фазам, гейн вперёд, уход
борта) + доля годных кадров канала в полёте (/mission/status ipm=/ipmf=) + жив ли VINS (bridge/odom).

Результат (2026-10-03)
----------------------
Прогоны: 0° ipm59_wl_baseline_20261003_194301, 15° tilt15_wl_baseline_20261003_201054,
25° tilt25_wl_baseline_20261003_201526 (по одному; первая пара 15/25 — 200117/200529 — выброшена:
генератор писал строку-пометку ДО %YAML:1.0, ray_tracer (cv2.FileStorage) падал, мост не открывался).

Сравнимо ТОЛЬКО верхнее плато (истина 1.0–1.5 м у всех трёх): нижнее в реплее легло на разной
высоте (0° — 0.42–0.74 м, 15° — 0.25–0.41 м по истине; спуск газом на фикс. время + разное смещение EKF
на старте −0.04 / −0.17 м), а судья берёт фазы только при palt > 0.3.

Верхнее плато, 3 висения + 2 разворота:
                         0°            15°           25°
  |бок ошибка| висение   0.112 м/с     0.069         0.016
  |бок ошибка| разворот  0.153         0.041         0.018
  СКО ошибки (шум)       ~0.068        ~0.067        ~0.060
  уход борта (сумма)     12.6 м        7.6 м         5.6 м
Весь полёт: годных кадров канала 96.1 / 96.6 / 95.7 % (брак — ALT GATE на земле; у 25° ещё 50 кадров
FEW LK); VINS odom 811 / 787 / 696, мост VINS→EKF открыт 71 / 73 / 60 % кадров.

Вывод: наклон вниз монотонно снимает СМЕЩЕНИЕ боковой скорости канала (0.11–0.15 → 0.02 м/с при 25°) и
вдвое уменьшает уход борта; шум (СКО) почти не меняется — он от тайминга углов, не от геометрии. VINS при
25° жив, но мост открыт реже (60 %) — горизонта в кадре меньше; цена для VINS/NN1 требует отдельной
проверки. По одному полёту на угол (разброс одиночных полётов кампании ~2×) — это направление, не цифра;
для решения о переделке крепления — серия 3× на угол и нижнее плато на одной высоте.
