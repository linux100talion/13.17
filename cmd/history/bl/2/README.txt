cmd/bl — BASELINE с 2026-09-30: ВЫХОД В УГЛАХ + DpVins ПОД ОТКЛИК БОРТА (dpvins/board1)
=====================================================================================

Зачем создан
------------
Итог переезда с override на углы (docker/sim/laptop_move.md §5.7, кампания cmd/att_out) и перевода
домена управления в СИ (2026-09-30). Прежний baseline (выход override в ALT_HOLD, dpvins/brake5_stop)
— cmd/history/bl/1/. На углах доказано в симе (cmd/att_out/README.txt, пп. 2–9):
  - канал углов летает как override: плечо, наклон, разгон и остановка совпадают (vins_init,
    rc_rev, roll_big);
  - арм и дизарм нодой по жесту пилота и её готовности;
  - домен в СИ (гейны в градусах, команда AttitudeCommand — рад, рад/с, м/с) — бит в бит с
    PWM-доменом по офлайн-A/B;
  - газ по карте ALT_HOLD самого полётника: полётник исполняет ровно заказанную скорость набора
    (спуск SA −0.148/−0.143 м/с при −0.15);
  - мягкий газ до реального контакта: пик у земли 0.68/0.51 → 0.24/0.17 м/с.
DpVins board1 (cmd/dpv_board/README.txt): с бортовыми параметрами отклика полётника
(ATC_ANGLE_MAX 20, ATC_INPUT_TC 0.3 — sitl_lv_profile) штатный brake5_stop у края устойчивости;
board1 держит висение 0.19 против 0.44 м/с, крен и тангаж на стике отзываются сильнее.

Что меняет
----------
Против cmd/history/bl/1 — два профиля в списке, остальное то же:
  mission/baseline  → mission/att_out   (BS_ATT_OUT=1; под реплеем mission/replay → mission/att_out_replay)
  dpvins/brake5_stop → dpvins/board1     (KI 0.32 → 0.12 °/(м/с)/с, VSMOOTH 0.3 → 0, FF 0.4 → 1.2 °/(м/с))
Схема режимов на углах (control_pkg/application/att_mode.py):
  SF вверх (наш стек)  → GUIDED_NOGPS, нода шлёт SET_ATTITUDE_TARGET (и на земле: арм нодой);
  SF не вверх          → ALT_HOLD «только пилот» — стики с RC-входа полётника (в симе мост /joy →
                         RC SITL, src/sim/joy_rc_bridge.py), нода молчит;
  LOITER/LAND/RTL      → штатные режимы полётника, нода молчит.
Арм: жест пилота (газ в пол + курс вправо 2 с) и готовность ноды; полётнику ARMING_RUDDER 0
(ставит sitl_lv_profile.py по BS_ATT_OUT). Дизарм: жест (газ в пол + курс влево 2 с) на земле.
load.BASELINE_STACK (тесты BootstrapConfig.baseline(), check.sh без аргументов) = этот список при
ATT=1 WT=1 без реплея.

Как летать
----------
  bash cmd/bl/bl.sh                    # выход в углах (штатно)
  ATT=0 bash cmd/bl/bl.sh              # вариант: выход override, ALT_HOLD, руддер-арм полётника
  WT=0 bash cmd/bl/bl.sh               # вариант: свой трим у каждого яруса + посев
  BS_PILOT=replay BS_REPLAY_SCENARIO=/lab/joystick/scenarios/vins_init_sa.json bash cmd/bl/bl.sh
Реплей vins_init_sa.json: взлёт на демпфере до 1 м, раскачка до открытия моста VINS→EKF, подъём
на 4 м, 15 с вперёд, стоп, посадка кнопкой SA, дизарм.
