**Отказ руддер-дизарма повторился (2026-08-23, lv1_replay_20260823_191230):**
после чистой посадки в LOITER (VINS жив, та же точка ~19 м, где 3 прогона
дизармились за секунды) FCU молча не дизармился — оба якоря по таймауту, нода
висела 12 мин, bag 41 ГБ, видео пришлось дорендеривать (bag без metadata.yaml
после kill → `ros2 bag reindex -s sqlite3`). ФИКС: страховка в Freefly — жест
дизарма на земле (thr,yaw ≤1160, баро ≤0.3) >8 с → cmd/arming(False), >12 с →
force_disarm (MAV_CMD 400/21196, новый метод MavrosActuator), >30 с →
FREEFLY_STUCK (миссия завершается, запись ограничена; урок реплея №1 — FCU
может отвергнуть даже force). Тест test_freefly_disarm_guard.py.
**ПРИЧИНА НАЙДЕНА (прогон 2 серии-2, 2026-08-23 вечер, повтор 2 из 5):**
баро/EKF-высота после касания ЗАСТРЕВАЕТ на ~1.4-1.5 м (gt=0.0, дрон на
земле) → детектор посадки FCU не взводится → руддер-дизарм отвергается;
рассосалось только со смертью VINS на земле (EKF-alt рухнула → дизарм прошёл
через 27 мин, bag 79 ГБ). Первая версия страховки гейтилась тем же битым
rel_alt≤0.3 и молчала — починено: «на земле» = баро ИЛИ gt_z≤0.3 (как детект
касания у Land; на Orin gt нет — остаётся баро). Открытый вопрос: откуда
залипание баро/EKF-высоты у земли (VINS z-дрейф? SIM-баро?) — копать отдельно.

прогоне 041803 FCU принял руддер-дизарм сам — отказ детектора посадки
