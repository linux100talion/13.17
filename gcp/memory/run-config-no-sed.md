Скрипты прогонов (`/tmp/rN_run.sh`, обёртки над `hover_series.sh`) НЕ порождать из
предыдущего через `sed 's/N=1/N=3/'` и подобные замены по коротким числовым шаблонам.
Писать файл целиком через heredoc.

Случай: `sed 's/PREFIX=R3/PREFIX=R4s/; s/N=1/N=3/'` попал не только в счётчик прогонов —
`BS_ROLL_OSIGN=1` стал `=3`, `BS_ROLL_CMD_GAIN=10` стал `=30`. Серия ушла в воздух с
перевёрнутым знаком оси и тройным гейном команды; поймано по выводу `grep`, который
печатал изменённые строки, прогон убит на шаге 0 (prearm) до арминга.

**Why:** имена ручек (`BS_*_OSIGN=1`, `*_GAIN=10`, `KP=16`) кишат теми же цифрами, что
и служебные параметры серии. Незамеченная подмена не падает, а даёт правдоподобно
странный полёт — и разбор уходит на «почему ось себя так ведёт» вместо реального
вопроса. Цена ошибки — час прогонов плюс ложный след в выводах.

**How to apply:** новый скрипт серии — целиком heredoc'ом с явными значениями. Если
всё же правишь копированием, сразу после — `grep -E "N=|OSIGN|GAIN|KP|KD"` по файлу и
глазами сверить с намерением ДО запуска. Смежное: [[no-edit-scripts-midrun]].
