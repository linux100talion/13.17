Сделано 2026-08-24 (просьба Андрея «респавнить дрон там, где я его посадил»).

- `src/lab/spawn_save.py <прогон> [имя]` — ОСНОВНОЙ путь: вынимает из прогона
  только позу и кладёт в `docker/sim/output/spawn/<имя>` (имя спросит, если не
  задано; `--list`/`--show`). Дальше прогон можно удалять, а старт звать по
  имени: `SPAWN_POSE=among_trees`. Имя разрешает `sim_up.sh` (не 6 чисел →
  файл `/root/output/spawn/<имя>`). Пресеты вне git (output/ в .gitignore) —
  так решил Андрей 2026-08-24. Шпаргалка: docker/sim/spawn.md.
- `src/lab/spawn_pose.py <каталог прогона>` — разовый вариант: из bag'а берёт
  последнюю истинную позу Gazebo (`/model/iris_cam/odometry`, ENU), зануляет
  roll/pitch, печатает `SPAWN_POSE="x y z 0 0 yaw"`. ROS не нужен — sqlite напрямую.
  Из прогона нужно РОВНО одно сообщение — семь чисел (xyz + кватернион).
- `SPAWN_FROM=<каталог прогона> bash src/lab/freefly_lv.sh` — то же одним env.
- `scripts/sim_up.sh` подставляет позу в `<pose>` модели `iris_cam` в КОПИИ мира
  в `/tmp` (репозиторный SDF чист), как патчи ветра/разрешения. Env применяется
  при СОЗДАНИИ контейнера → только `fresh-start`; постоянный дефолт — строка
  `SPAWN_POSE=...` в `docker/sim/.env`.

Проверено на живом стеке: борт встаёт ровно в точку с её курсом и стоит
неподвижно (бит-в-бит 48 с) — но ТОЛЬКО с ветром, см. [[sim-ground-no-friction]].

**Why:** серия «полёт за полётом» из одной точки без ручной правки мира.

**How to apply:** истинная поза Gazebo в таком прогоне начинается НЕ с нуля —
скриптам разбора, считающим старт началом координат, скармливать ту же
`SPAWN_POSE`. Полётнику сдвиг безразличен (home/origin EKF ставится на буте).
КУРС пресета ≠ восток ломал LOITER-на-VINS (разнос) до yaw-якоря кадра —
механизм и фикс: [[vins-frame-yaw-anchor]]; курс-нейтральность доказана
полётом 2026-08-24 с курса −169°. Связано: [[sim-geo-anchor-kyiv]].
