Пилот (freefly, yaw_kp=0): yaw — «пружина, наматывающаяся вокруг дрона». Серия
`docker/sim/output/joystick/yaw_ab_ki60_win03/spring/{long,short}/{left,right}/{1,2}`
(2026-08-27), разбор — `src/lab/yaw_spring_check.py`.

**Диагноз (доказан цифрами):** в pos-режиме DpYawHold D-член брался разностью ошибки,
куда утечка (leak=8с) подмешивает −err/leak → при kp=0 скрытый П-член kd/leak=0.75
PWM/ед. по НАКОПЛЕННОЙ ошибке. Контур не успевает за уставкой (заказ ~50°/с, борт
11–14°/с) → ошибка наматывается до 350–430° (уставка за длинный пресс убегала на 3–4
оборота). Итог: намотка душит собственную команду (PWM пресса −47→−29), после
отпускания контур разматывает борт ОБРАТНО на 92–96% разворота (+349° → −330°, τ≈10 с).
Пик обратного PWM = kd/leak·S·err ±3%. Конфиденс 0.97–1.00 — гейты ни при чём.
Юнит-тест утечку в D оценивал «0.6% за кадр» — мерил при err≈0 (слепое пятно).

**Фикс (внесён 2026-08-28, af40901; ДОКАЗАН полётом в тот же день):**
1. `_dot`: D-член кормится замеренной скоростью кадра (принятый step), утечка правит
   только накопитель → при kp=0 намотанная ошибка ИНЕРТНА (регрессия в
   test_flow_strategies.py «пружина: …»).
2. `yaw_pilot_gain` / `BS_YAW_PILOT_GAIN` (PWM при полном стике, 0=выкл, конфиг-дефолт
   0): стик жив → PWM прямо со стика, контур обнуляется каждый тик; отпустил → демпфер
   с чистого листа. freefly_lv.sh включает 130 ≈ 60°/с (замер spring: ~0.45 °/с на PWM).
   Токенам yaw_l/yaw_r передача не нужна (калиброваны через уставку) — не включать.

**Лётное доказательство (2026-08-28, joystick/yaw/{long_right,short_right}, c099356):**
длинный пресс 10 с → −186.5°, возврат +7.6° = 4% (было 92–96%); короткие прессы —
возврата нет, лишь докат −7..−14° в ту же сторону (t50 0.1–0.2 с — инерция + slew,
не контур). err@rel=0 и sp_move=0 на всех прессах (контур обнулён передачей), PWM
после отпускания ≈0. Авторитет честный: 42.7 PWM → 18.7°/с = 0.44°/с на PWM — ровно
замеренный коэффициент, гейн 130 даёт ~57–60°/с на полном стике. Пилот: «стал прям
сильно лучше». Руддер-жесты арм/дизарм на земле идут передачей с клампом ±130 — штатно.
Реплеи старых spring-бэгов теперь ведут себя иначе (передача перехватывает стик) —
с прежними сериями бит-в-бит не сравнивать.
