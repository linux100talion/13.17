Скрипты запуска (профили → env → `src/lab/freefly_lv.sh`) кладутся в `cmd/<имя>/<имя>.sh`,
рядом обязательный `cmd/<имя>/README.txt`: зачем создан, что меняет против эталона и для
чего, как летать (сценарий пилота), чем судить (инструмент + критерии успеха/провала),
результат — дописывается после полёта. Скрипт не зависит от cwd (корень репы от своего
расположения, `/../..`), ручки берёт из `src/control/profiles/*/*.txt` (baseline + кандидат),
внешний env сильнее. Общая шпаргалка — `cmd/README.txt`. Первый: `cmd/1` — A/B DpVins ki 30
под порывами (кандидат `profiles/dpvins/ki30.txt`, стенд `src/lab/dpvins_gust_stand.py`).

**Why:** пользователь хочет, чтобы каждая лётная команда была самодокументированной
единицей: через месяц по README понятно, зачем летали и что проверяли, без раскопок чата.

**How to apply:** новый скрипт запуска = новая папка `cmd/<имя>/` + `<имя>.sh` + `README.txt`
по разделам выше; не класть скрипты в корень `cmd/`; после полёта дописать раздел
«Результат». Связано: [[dphold-vs-dpvins-gusts]].
