Полёт lv2_joy_20260906_195742 (откаченный код, ветер база 2 + порывы 5, круги пилота на стиках
280–332 с с рысканием 11–17°/с). Симптом: последние 100 с на DpHold борт едет вправо 1.5–2.6 м/с при
стиках в центре (истина Gazebo), канал IPM боковую скорость не видит (−0.4…+0.5), продольный работает
(гейн 0.5–1.0), трим крена +33…+68 гонит борт ПО сносу, стрелка HUD: направление ±20° от истины, но
ВЕЛИЧИНА 5.5–12 м/с при истине 2–5 (трим не ветер). Гейн боковой оси к истине по 10-с окнам: 0.57–0.88
до кругов → 0.32 → 0.13 → −0.07…+0.14 до посадки. Ориентация EKF = истине, высота перцепции верна,
земля вся мелкая — не рама, не фактура, не высота.

**Механизм (perception/ipm.py `_wz_debias`):** деротация вычитает из потока полосы поле разворота
X·(ω_z − оценка нуля)·dt, X = 3–6 м (× alt/3). Оценка нуля — ФВЧ τ 2 с с гейтом «двигать только при
|ω_z − оценка| < 0.1». Круги нарастали медленно → оценка ползла за вращением (реплей кадров: 2 → 5 →
12 → 16°/с к 320 с), после остановки |ω_z − оценка| = 16°/с > гейта → оценка ЗАМЕРЛА (15–17°/с до
посадки) → деротация вычитает фантом X·0.27 рад/с ≈ 1.5–3 м/с боковой → демпфер «убирает» фантом
реальным движением → канал читает ~0, борт едет, трим наматывается. Побочно: фантом +2 м/с на
376–380 с ложно сработал чек занижения VINS (scale25: scl=1, мост закрыт, ярус 1 сброшен).

**Доказательство:** повтор реальных кадров bag через FlowEstimator (scratch wz_replay.py, PYTHONPATH на
исходники, лётные ручки, palt из статуса, IMU как у ноды): с гейтом 0.1 — оценка 16°/с после кругов,
гейн боковой 0 (совпадает с записью); без гейта — оценка отпускает за секунды, гейн 0.5–1.0 весь полёт;
с ФИКСОМ (abs-гейт 0.1 + кап 0.05) на тех же кадрах: оценка 0–1.9°/с весь полёт, гейн боковой
0.82–1.07 везде (на кругах 0.88–0.95 против 0.47–0.83 у старого, после кругов 0.82–0.99 против ~0),
vlat повтора = истине (440 с: −1.71 при истине −1.98; старый 0.30, запись 0.01).

**Why:** гейт относительно оценки защищает «ноль» от резкого разворота, но медленный разгон
вращения обходит его (шаг < 0.1 рад/с от текущей оценки), а после остановки тот же гейт не даёт
оценке вернуться — самоблокировка. Настоящее смещение гироскопа (уже компенсированного EKF) —
0.003–0.028 рад/с, оценка выше — это разворот, а не ноль.

**How to apply:** ФИКС (ipm.py): гейт по АБСОЛЮТНОЙ |ω_z| (разворот — не двигать, висение — двигать) +
кап |оценка| ≤ `ipm_wz_bias_max` 0.05 рад/с (BS_IPM_WZ_BIAS_MAX, 0 = без капа), старт оценки тоже под
капом; `_acc_debias` гейта не имеет — капкана нет. Тест test_ipm_wz_bias.py (сценарий 195742: пик
оценки 2.9°/с, через 5 с после стопа 0.2°/с; смещение 0.02 сходится; кап). ПОДТВЕРЖДЁН полётом 2026-09-06 (cmd/10,
ветер 2 + порывы 5, круги на стиках → висение; пилот: «летает»), закоммичен в nn2_c3_laptop_wind. Связано: [[damper-low-alt]] (ab_gate — откуда гейт), [[dpvins-gust-restart-scale]]
(ложный scl на фантоме), [[wind-trim-shared]] (полёт шёл на откаченном коде — WindTrim ни при чём).
