Разбор 2026-08-24 (прогоны lv1_joy 212409/213830, спавн с курсом −169°): «LOITER
не подхватился» оказался разносом — LOITER латчился МГНОВЕННО, но борт с
центральными стиками разгонялся 0.2→3.2 м/с за 3 с (до 15 м/с).

Механизм: мир монокулярного VINS рождается с курсом ПЕРВОГО кадра камеры (yaw
у VIO ненаблюдаем), а `ray_tracer` якорил кадр на EKF только трансляцией
(допущение «выровнены по рысканью»). Замер по bag: трек VINS повёрнут к истине
на +169..171° = ровно курс спавна, при ИДЕАЛЬНОМ масштабе (0.94–1.04). После
глушения GPS каждое смещение VINS входило в EKF почти перевёрнутым →
положительная ОС LOITER. Контроль: штатный спавн (курс 0) — поворот +8.6°,
LOITER держал. Наш стек (демпфер/VinsHold) поворота не чувствует — замкнут
внутри кадра VINS; поэтому «CH6-вверх летает, центр — уносит».

Фикс: `FrameAnchor` (src/nav/nav_pkg/nn1/frame_anchor.py, чистый python) —
латчит Δyaw = yaw_EKF − yaw_VINS (пара ориентаций одного тела) + трансляцию;
жёсткая подтяжка перелатчивает И поворот, мягкий дожим — только t; засечка NN1
правит только t (yaw по ориентиру — отдельный шаг). corrected_odom/vision_pose
теперь целиком в кадре EKF (позиция+ориентация+world-скорость). Офлайн-тест
`src/nav/test/test_frame_anchor.py`; реплей хороших bag'ов: Δyaw −1.5°/+4.3°,
трек не хуже старого (1.3–4.2 м).

**Why:** любое использование позы VINS в кадре EKF/ENU обязано пройти через
выравнивание по рысканью — «совпадение рамок» держалось только на привычке
стартовать носом на восток.

**How to apply:** ✅ ДОКАЗАН полётом 2026-08-24: `SPAWN_POSE="-0.6018 -11.0809
0.2450 0 0 -2.95235" BS_SF_MASTER=1` — LOITER сработал автоматически по
лесенке и держал (та самая точка/курс, что разносили 212409/213830). Диагноз
подобных разносов на будущее: угол трека VINS к истине по bag (Прокруст без
масштаба) — если ≈ курсу спавна, это кадр, а не VINS/гейны; в логе якоря
смотреть «Δyaw=…°» ≈ минус курс спавна. Связано: [[spawn-from-landing]],
[[lv-loiter-series]], [[sf-master-ladder]].
