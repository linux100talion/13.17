**Прогон 214015 (первый полёт с полом): «ниже 1 м не слушает стики» —
ДИАГНОЗ ДОКАЗАН, три механизма:**
1. **conf-blend душит IPM-оси** (ГЛАВНЫЙ): _FlowDamper1D.update умножает
   выход на _blend(s.flow_conf) — conf ПОЛНОКАДРОВОГО потока, а сигнал
   Dp*Rate осей — IPM-канал (свои фичи в варпе, 99% годен). Ниже ~1.2 м

   На ≥1.5 м blend=1.0 → фикс (авторитет IPM-осей = 1, не по чужому
   conf) регресс-нейтрален для отлётанных серий.
2. Гейт земли 0.15 по EKF-z с биасом −0.3: истинные <0.45 м — код 1 в
   77% тиков → hold+fade → мёртвая ось. (Пол выше этого работает: канал
   годен 99% на 0.5-1.2.)
3. «Стабилизатор не работает ниже 1.5» = гейт LOITER alt>1.5 (rel_alt
   баро) в Freefly/hud_status — LOITER не залатчился ни разу за полёт,
   по построению.
⚠️ Методика: штампы /joy — WALL-время, тиков ноды — sim; interp joy↔sim
без смещения даёт мусорные corr (nan). Цель оси есть прямо в /flow_dbg7.x.
