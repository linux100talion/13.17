**Пока идёт прогон симуляции — НЕ править файлы `src/lab/*.sh`** (они смонтированы
в контейнер как `/lab` и исполняются прямо с диска хоста). Python-файлы править
можно: colcon install делает КОПИЮ, работающая нода их не видит.

**Why:** bash читает скрипт не целиком, а по мере исполнения, по байтовому
смещению. Вставка строк в середину сдвигает всё ниже — интерпретатор продолжает
с прежнего офсета и попадает в середину строки. 2026-07-29 в прогоне J1c это дало
`bootstrap_arch2.sh: line 106: n: command not found`, после чего **миссия
запустилась второй раз в тот же бэг**, а `capture_scene.sh` упал с
`syntax error near unexpected token '('` — заливка видео и переименование бэга не
выполнились, спасать пришлось руками.

**How to apply:**
- Правки shell-обвязки складывать до конца прогона; код нод (`src/control`,
  `src/mission`) править можно свободно.
- Если правка срочная — сначала прибить прогон целиком, потом править, потом
  перезапускать (прогон атомарен, см. CLAUDE.md).
- Признак, что это уже случилось: в логе `command not found` на одиночном
  символе или `syntax error` в скрипте, который заведомо валиден
  (`bash -n` на диске проходит).
