RADIOMASTER TX12 (MKII, EdgeTX) — органы управления и карта каналов
====================================================================

Пульт проекта: Radiomaster TX12 MKII CC2500, внешний модуль ELRS 915 МГц (ES900TX),
приёмник ES900RX на борту (CRSF в полётник + отвод на Orin, hw.txt). В симе пульт идёт
по USB как джойстик «OpenTX Radiomaster TX12 Joystick» → /dev/input/js0 → /joy.

ОРГАНЫ (физически, вид от пилота)
---------------------------------
  Слева:   SA — кнопка (без фиксации)
           SB — 3-позиционный
           SE — 3-позиционный
  Справа:  SD — кнопка (без фиксации)
           SC — 3-позиционный
           SF — 3-позиционный
  Стики:   левый — газ / курс, правый — тангаж / крен (Mode 2)
  (крутилки S1/S2 — если используются, дописать)

КАРТА КАНАЛОВ (микшер модели EdgeTX → USB-джойстик → /joy) — ПРОВЕРЕНО 2026-10-02
-----------------------------------------------------------------------------------
Как читается в симе: CH1…CH8 → /joy axes[0..6] (CH7 и CH8 у TX12 по USB садятся на ОДНУ ось
axes[6] — CH8 держать ПУСТЫМ); CH9…CH32 → кнопки buttons[0..23] (нажата при значении канала
> 0). Сверка пробником (руку на орган, потом запуск):

  python3 src/lab/joystick/js_probe.py /dev/input/js0 20

  канал  /joy        орган        микс (EdgeTX)      значения по USB             назначение в стеке
  -----  ----------  -----------  -----------------  --------------------------  ----------------------------
  CH1    axes[0]     правый стик  крен (AETR)        −1…+1                       крен
  CH2    axes[1]     правый стик  тангаж             −1…+1                       тангаж
  CH3    axes[2]     левый стик   газ                −1…+1, в покое 0 (самоц.)  газ: скорость набора
  CH4    axes[3]     левый стик   курс               −1…+1                       курс
  CH5    axes[4]     SE (3-поз.)  SE                 вверх +1 / 0 / вниз −1      режим полётника (FLTMODE_CH=5);
                                                                                 нода не читает. Борт: вниз ≈1000
                                                                                 FLTMODE1, центр FLTMODE4, вверх FLTMODE6
  CH6    axes[5]     SC (3-поз.)  SC, weight +100    вверх −1 / 0 / вниз +1      потолок лесенки: вверх демпфер,
                                                                                 центр VINS, вниз LOITER
  CH7    axes[6]     SF (3-поз.)  SF, weight +100    вверх +1 / 0 / вниз −1      SF-мастер: вверх — стабилизация,
                                                                                 иначе сырые стики (MANUAL)
  CH8    —           —            ПУСТО              —                           по USB дерётся с CH7 — не трогать
  CH9    buttons[0]  —            пусто              —                           свободна
  CH10   buttons[1]  SA (кнопка)  SA, weight +100    нажата 1 / отпущена 0       МЯГКАЯ ПОСАДКА (BS_LAND_JOY=b1)
  CH11   buttons[2]  SD (кнопка)  SD, weight +100    нажата 1 / отпущена 0       ВОЗВРАТ ДОМОЙ SMART_RTL (BS_RTH_JOY=b2)
         —           SB (3-поз.)  не назначен        —                           свободен

ЗНАК ОСИ — ТОЛЬКО ПРОБНИКОМ, ОТДЕЛЬНО НА КАЖДОЙ. У тумблеров EdgeTX вверх = −100. По USB CH6
отдаётся как есть (weight +100 → вверх −1), а CH7 (HID «Slider», ABS_THROTTLE) — с обратным
знаком (weight +100 → вверх +1). Совет «weight −100 в CH6» из прежней памятки на этом пульте
давал обратное направление (2026-10-02).

КАК ПЕРЕДЕЛЫВАЛИ (2026-10-02): было CH5 SE, CH6 SF, CH7 SB, CH9 SA, CH10 SD, SC нигде — стек
сима ждал другое (SA не сажала, SD сажала, лесенкой рулил SF, мастером SB). Перенесли: CH6 → SC,
CH7 → SF, SB убран, SD CH10 → CH11, SA CH9 → CH10; копия модели до правки сделана на пульте.

Жесты (стики): газ вниз + курс вправо 2–3 с — арм; газ вниз + курс влево 2–3 с — дизарм.

НА РЕАЛЬНОМ БОРТУ каналы идут по CRSF в полётник (CH5 = режим полётника) и через отвод на
Orin (/dev/ttyTHS1, crsf_joy); раскладка CH5–CH8 на борту ещё не закреплена (hw.txt).
