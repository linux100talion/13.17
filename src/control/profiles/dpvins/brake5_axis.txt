# КАНДИДАТ A/B — DpVins brake5_tail + ПО-ОСЕВАЯ ЗАЩЁЛКА ТРИМА (BS_DPVINS_LATCH_AXIS=1).
# Всё остальное = dpvins/brake5_tail.txt (brake 5, кап 2.0, brake_t −1, ki 8 — доказан
# висением cmd/4: пик 2.36 против 4.6–5.5). Дата: 2026-09-06.
# Цепочка: cmd/4 в движении (lv2_joy_20260906_113224, крейсер стиком тангажа, ветер
# сбоку) вскрыл: на живом стике трим DpVins не учится ВООБЩЕ — любой стик морозит трим
# по ОБЕИМ осям (`frozen = stick or …`, sat тоже ИЛИ). У демпфера защёлка _TRIM_LATCH
# ПО-ОСЕВАЯ: каждый _FlowDamper1D морозит только свой И-член, свободная ось (крен при
# стике тангажа) держит линию и учит трим. Цена по истине Gazebo (боковой снос тела на
# плечах стика ≥ 3 с): DpHold 0.16 м/с (3.6 м за 23 с); DpVins 0.76 / 0.58 / 0.56 м/с
# (12.3 / 6.1 / 15.5 м) — второе плечо с ВЕРНЫМ тримом висения 57 PWM: боковая сила на
# ходу больше, чем в висении (лобовое ∝ |v_возд|·v_возд, ~×1.9 при 1.6 вперёд и 1 сбоку),
# её надо доучивать на ходу; P-канал kp 32 держит остаток 1 м/с на 32 PWM.
# latch_axis: морозится только компонента вдоль ДВИЖИМОЙ оси (и её хвост до гвоздя),
# свободная ось учится рабочим ki 8 (не ki_trim: гвоздя на стике не будет). Движимую ось
# не учим — выучила бы «ветер + лобовое крейсера», после стопа рывок (причина защёлки
# демпфера). sat по осям.
#
# ОЖИДАНИЕ: висение без стика — поведение ИДЕНТИЧНО brake5_tail (стенд 2.44/0.04, тест
# §23 старое/новое); крейсер с ветром сбоку — боковой трим доучивается со скоростью
# ki·v_lat ≈ 8·0.6 ≈ 5 PWM/с (постоянная времени ~10 с на 50 PWN), снос за плечо 10–28 с
# должен упасть с 6–15 м к ~3–5; на коротких плечах (< 5 с) выигрыша почти нет — это
# ki, не kp. Рывка после стопа быть не должно (движимая ось заморожена как раньше).
# РИСК: свободная ось учится на лаге 0.9 с при ki 8 — раскачки не ждём (ki 15 в
# висении не качал), но боковой контур на ходу полётом не проверялся; шум VINS на ходу.
#
# ЧЕМ ДОКАЗЫВАТЬ: полёт как 113224 — висение на DpVins до трима (стрелка ветра встала),
# затем плечи стиком тангажа 10–30 с с ветром СБОКУ (курс поперёк 98°), оба направления,
# стоп, повтор; контроль DpHold в том же полёте. Разбор — сегменты стика ≥ 3 с
# (боковая скорость тела по истине): успех — vlat_mean ≤ 0.3 м/с на плечах ≥ 10 с,
# стрелка ветра на ходу ЖИВАЯ (wnr меняется), без рывка после стопа (|v| после отпускания
# гаснет монотонно) и без качания; провал — снос как был (≥ 0.5) → смотреть sat/знак;
# рывок после стопа → хвост защёлки движимой оси не сработал; качание боковое → ki 6.
