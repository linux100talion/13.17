# КАНДИДАТ A/B — скорость VINS из TWIST одометрии вместо конечной разности позы
# (BS_VINS_VEL_SRC=twist). Всё остальное = vins/baseline.txt. Дата: 2026-09-06.
# Цепочка: DpVins на kp 32/40 уступает демпферу kp 90 авторитетом — разгон через гвоздь
# и возврат на тримe-излишке 1.2 м/с против 0.7 (bag 130326, brake_phase.py); kp опущен
# из-за лага петли ~0.9 с (скорость 0.35 + vsmooth 0.3 + наклон 0.26). Скорость сейчас —
# конечная разность позы по штампам + EMA 0.4 (VinsTrack). Twist = скорость из самого
# сообщения одометрии (состояние эстиматора, преинтеграция IMU).
# ПРОВЕРКА по bag 130326 (src/lab/vins_twist_check.py): рама twist = рама позы (МНК-поворот
# к истине +3.2° против +2.7° у разности), масштаб 1.008, лаг к истине по штампам 0.00 с
# против 0.14 у разности, шум на висении 0.008±0.005 м/с против 0.025±0.049 (×10 тише).
# ОЖИДАНИЕ: лаг петли 0.35 → ~0.11 (приход). Стенд τ 0.11 (ki 8 brake 5 кап 2, brake_t −1):
#   kp 32: пик 2.33 / остаток 0.04 / vmax 1.40 (τ 0.35: 2.44 / 0.04 / 1.29) — сам по себе
#   пик не меняет, окно ki шире (~20 %: ki 12 → 2.56, ki 15 → 3.81 против 3.83/5.57).
#   kp 40 → 2.15/0.02/1.25; kp 60 → 2.49/0.01/0.86; kp 90 → 2.27/0.01/0.76 — kp режет
#   СКОРОСТЬ (vmax), это и есть разгон/возврат; следующий шаг после доказательства twist.
# Гейт здоровья (vins_sane: потолок 12, висение >3, занижение против IPM) тоже на twist —
# артефакта догоняющей пачки (114248) у twist нет по построению. Детект перерождения и
# зрелость — по-прежнему на разности (VinsTrack/VinsRipeness).
# РИСК: twist на реальном ArduCam/боевом VINS не проверен (сим: 0.008 м/с шума); при
# перерождении VINS twist переживает скачок так же, как поза. vsmooth 0.3 оставлен.
# ЧЕМ ДОКАЗЫВАТЬ: полёт как cmd/5 (висение под порывами + плечи стиком) — brake_phase.py:
#   успех — цикл не хуже 130326 (пик от гвоздя ≤ 2.2, перелёт ≤ 2.1, BRAKE входит не
#   позже +3.5 с), spd= статуса без дрожи на висении, σθ не хуже, reb/scl 0;
#   провал — новый звон/дрожь (шум twist в петле) → vsmooth 0.5; демоуты по гейту → V_MAX.
