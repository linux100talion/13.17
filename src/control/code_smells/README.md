# Code smells control_pkg / mission_pkg

Журнал известных запахов кода, которые мы ОСОЗНАННО оставляем на время поиска и активной
разработки. Запах ≠ баг: код работает, но устроен так, что следующая правка рядом с ним
легко ломает что-то неочевидное (как WindTrim в первой версии). Заводим запись, когда
запах уже укусил или когда заплатка положена вместо правильного фикса.

Формат записи (один файл на запах, имя говорящее):

- **Что** — в чём запах, одной фразой.
- **Где** — файлы и строки.
- **Чем укусил** — конкретный инцидент (полёт/коммит), если был.
- **Заплатка сейчас** — что стоит вместо фикса и почему этого мало.
- **Правильный фикс** — что сделать, какие риски, чем доказать (A/B бит в бит, тесты, полёт).
- **Класс** — обобщение: какое правило нарушено, где ещё такое может всплыть.

Записи:

- [Тень композита DpHold в стеке яруса 1](shadow_composite_tier1.md) — мёртвый выход с живыми
  побочными эффектами; укусил WindTrim (два интегратора на одном триме), заплатка — владелец.
