# swips/ — мета отснятых прогонов

По файлу `<NAME>.env` на каждый прогон: коммит, на котором он снят, все `BS_*` и
`WIND_*`, разрешение камеры, список записанных топиков. Пишется автоматически в
`calib_run.sh` рядом с бэгом.

**Зачем копия в репе.** Оригиналы лежат в `docker/sim/output/`, а этот каталог
в `.gitignore` и вычищается: бэги весят гигабайты, серия на 9 прогонов съедает
четверть диска, и рано или поздно `make clean` или нехватка места сносят всё
разом. Бэг восстановить нельзя, а вот **чем он снят** — можно, если мета уцелела.
Здесь она уцелевает: 4 КБ на прогон против 2.6 ГБ на бэг.

Без этого через месяц прогон неотличим от соседнего: `T2s` (штиль) и `V2s`
(ветер 5 м/с) по именам одинаковы, а сравнивать их нельзя.

## Как читать

```bash
cat src/control/swips/B5s1.env                          # чем снят один прогон
diff src/control/swips/{B4s1,B5s1}.env                  # чем две точки свипа различаются
grep -l "BS_ROLL_RATE_KI=30" src/control/swips/*.env    # где эта настройка уже летала
grep -h "^# commit" src/control/swips/C*.env | sort -u  # на каком коде снята кампания
```

Разбор по сериям и готовые команды повтора — в `cmd.md` рядом, §7.

## Оговорки

⚠️ **Мета — не гарантия, что ручка доехала до ноды.** Она пишется из окружения
`calib_run.sh`, ДО запуска стека. Именно так пропал свип `B3s`: `BS_ROLL_RATE_KI=5`
записан в мету, а до ноды не доехал, и прогоны отлетели с нулём. С тех пор проводку
проверяет `check_knobs.sh`, но у прогонов старше коммита `64d94c2` такой проверки
не было — их мету читать как «что просили», а не «что применилось».

⚠️ **У серий `T`–`Y` ветра в мете нет** — запись `WIND_*` появилась позже. Для них
скорость ветра берётся из заголовка лога:
`grep "ВЕТЕР.*ВЫЛЕТ" docker/sim/output/*.log`. Мета с `WIND_*` есть у `B`, `C`, `Z`.

⚠️ **Мета без бэга = прогон не состоялся** (упал на арминге, оборвался ребутом).
Файл пишется в начале, бэг — в конце. Такие есть: `E3f1`, `E5f1`, `E6f1`, `E7f1`,
`E9f1`, `E9s3`, `H2s3`, `K4s3`, `M2s5`, `N2s3`, `R2s1`. Данных за ними нет.

## Обновление

Каталог наполняется вручную после кампании — автокопии нет намеренно, иначе в репу
поехала бы мета оборванных и отладочных прогонов:

```bash
cp docker/sim/output/*.env src/control/swips/
```
