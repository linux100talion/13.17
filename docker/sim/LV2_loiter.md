# LV=2: LOITER-на-VINS при «GPS отсутствует с бута»

Профиль **LV=2** — модель боевого борта БЕЗ приёмника GPS: борт не видит
спутников НИ СЕКУНДЫ, EKF с земли живёт на vision, origin ставится руками.
Доказан полётами 2026-08-24 (реплеи lv_flight2, чистый прогон
`lv2_replay_20260824_041803` — FREEFLY_DONE): **старт→LOITER 72 с против
96-116 у LV=1** — вся экономия из исчезнувшего GPS-прогрева EKF (~8 с вместо
43-44). С 2026-08-26 LV=2 + SF-мастер — дефолт (`docker/sim/env.default`):

```bash
bash src/lab/freefly_lv.sh          # дефолт .env: LV=2 BS_SF_MASTER=1 (см. env.md)
```

Документ — брат `LV1_loiter.md`: общая механика (якорь кадра ray_tracer,
VELXY=0 против фантомной IPM-скорости, «с failsafe не воюем») описана там и
здесь не повторяется; ниже — что в LV=2 ДРУГОЕ и полная хронология.

## Отличия от LV=1 одним экраном

| | LV=1 | LV=2 |
|---|---|---|
| GPS | жив на буте, глушится в полёте (фаза 6) | отсутствует с бута (`SIM_GPS1_ENABLE=0` в eeprom ДО старта); глушить нечего |
| EKF на буте | греется на GPS (~43 с) | aiding с земли от МОСТА нулевой позы (~8 с) |
| Источники EK3 | 3/3 → свап на 6/0 по зрелости | 6/0 стоят в eeprom с бута; очередь лишь ДАТИРУЕТ extnav_ready зрелостью |
| Origin EKF | от GPS | руками: `SET_GPS_GLOBAL_ORIGIN` до подтверждения (`BS_SET_ORIGIN=1`) |
| Высота миссии | global rel_alt (EKF) | сырой баро (`BS_ALT_SRC=baro`: global без GPS замерзает) |
| Высота перцепции | global | EKF local z (`BS_PERC_ALT_SRC=local`: гладко, без лага, живёт без VINS) |
| Селектор | легаси-CH6 (вверх/центр/вниз) | лесенка SF-мастера (дефолт `BS_SF_MASTER=1`) |

## Селектор: лесенка SF-мастера

- **SF (CH7) не-вверх = MANUAL** при любом SC: сырые стики, всегда ALT_HOLD —
  перехват одним щелчком (safety-seize, Арбитр выше шага).
- **SF вверх** → SC (CH6) задаёт ПОТОЛОК лесенки, борт всегда на лучшей
  ДОСТУПНОЙ ступени ≤ потолка:

| SC | Потолок | Что летит |
|---|---|---|
| вверх | 0 | демпфер (IPM-скорости → PWM; позицию не держит) |
| центр | 1 | + VinsHold по готовности VINS (позиционный PID по сырому VINS) |
| вниз | 2 | + штатный LOITER по зрелости (позицию держит FCU по EKF-от-VINS) |

Ключевое отличие от легаси-центра: позиция «loiter» до зрелости — это
демпфер/VinsHold, а НЕ голый ALT_HOLD (в легаси борт при закрытом гейте
дрейфовал с ветром — прогон 2026-08-20). Деградация симметрична: VINS протух
в LOITER → откат на ярус ниже с гистерезисом 3×fresh. Стек яруса LOITER
пустеет ТОЛЬКО когда FCU фактически залатчил режим; пока идёт ре-ассерт —
держит текущий ярус (лог: `держу текущий ярус лесенки в ALT_HOLD`).

⚠️ Нужен микс SF→CH7 в EdgeTX; реплей СТАРЫХ сценариев (без ключа `"sf"`) —
только с `BS_SF_MASTER=0` (иначе весь полёт на сырых стиках).

## Хронология полёта

```
фаза   −1        0          1        2       3           4          5        6
     eeprom → origin → EKF aiding → арм → взлёт → VINS init → зрелость → SC-вниз
источник │                с земли (мост 0,0,баро) ──┐
EKF      │  POSXY=6/VELXY=0 стоят с бута            └→ поза VINS (ray_tracer) ──→
лесенка  │                          ярус 0 (демпфер) → ярус 1 (VinsHold) → ярус 2 (LOITER)
```

### Фаза −1 — eeprom ДО бута (`sitl_lv_profile.py 2`)

`freefly_lv.sh` пишет в eeprom: `VISO_TYPE=1`, `SIM_GPS1_ENABLE=0`,
`EK3_SRC1_POSXY=6`, `EK3_SRC1_VELXY=0` — борт СТАРТУЕТ безжпсным, EKF ждёт
vision с земли. Плюс `ARMING_SKIPCHK=-1` (урок: в 4.8 `ARMING_CHECK 0` —
переименован и молча игнорировался, PreArm-чеки были включены все LV-серии).

⚠️ **Геопривязка — ТРИ точки обязаны совпадать** (урок `lv2_replay_..._034433`,
59 ГБ земли): `<spherical_coordinates>` мира Gazebo, дом SITL (`SIM_HOME` в
`sim_up.sh`) и origin ноды (`BS_ORIGIN_LAT/LON/ALT`). EKF строит из origin
модель магнитного поля (WMM) и сверяет с магнитометром, который рисуется от
дома SITL: разъедутся → `PreArm: Check mag field (z diff:999>200)` — арм
невозможен, freefly ждёт вечно (теперь страховка: 300 с без арма →
FREEFLY_NOARM). Сейчас все три — Киев.

### Фаза 0 — бут ноды: origin руками + очередь-датировщик

- `set_origin` шлёт `SET_GPS_GLOBAL_ORIGIN` раз в 2 с до подтверждения
  (лог: `origin подтверждён (gp_origin)`). Без origin EKF не начнёт aiding —
  LOITER мёртв весь полёт (нода громко предупреждает).
- Очередь `EK3_SRC1_*` здесь НЕ переключает источники (они уже стоят), а
  (а) самовосстанавливает eeprom, если его увёл чужой профиль (LV=0 вернул
  3/3), и (б) ДАТИРУЕТ `extnav_ready` зрелостью VINS: `POSXY=6`
  переписывается по гейту зрелости → гейт LOITER и HUD READY открываются на
  той же зрелости, что в LV=1 — семантика не упрощена.

### Фаза 1 — мост нулевой позы: EKF aiding С ЗЕМЛИ

До первой одометрии VINS `ray_tracer` публиковать нечего, а EK3 стартует
aiding ТОЛЬКО на земле (в воздухе не начинает — урок LV4). Мост
(`_pose_bridge` в bootstrap_node) издаёт в `/mavros/vision_pose/pose` позу
`(0, 0, баро)` + текущий yaw с земли и весь набор высоты. x=y=0 на
вертикальном взлёте — честное приближение. С ПЕРВОЙ одометрией VINS мост
замолкает НАВСЕГДА: топик переходит к ray_tracer (два издателя позы
недопустимы; перекрытия нет, стык гладкий — кадр ray_tracer якорится на EKF,
обе стороны ≈ (0,0,alt)).

`ekf_warmup` (WaitEkfPos) ждёт свежий `local_position` — EKF держит позицию
на мосте уже через ~8 с от старта ноды (vs 43-44 с GPS-прогрева LV=1).
HUD: «EKF WARMUP» (жёлт) → «EKF READY - TAKEOFF OK» (зел).

### Фазы 2-3 — арм, взлёт (ярус 0), init VINS на отрыве

Арм руддером (SF вверх, газ вниз + yaw вправо). Взлёт на демпферах.
Вертикальный климб в текстурной сцене инитит монокуляр почти сразу: **init
VINS 0.3-2.1 с после отрыва** (контрпример: непрерывный yaw на климбе — VINS
не инитится весь полёт). Кадр VINS выравнивает FrameAnchor (Δyaw +
трансляция по паре поз EKF/VINS): мир монокуляра рождается с курсом первого
кадра, спавн с курса −169° без якоря разносил LOITER положительной ОС.

### Фаза 4 — ярус 1: VinsHold по готовности

Гейт готовности — `BS_VINS_MIN=300` odom (~2 с потока маловато посреди
манёвра — урок LV6). Лесенка сама поднимает ярус при потолке SC ≥ 1,
лог: `ЛЕСЕНКА: ярус VINSHOLD`.

### Фаза 5 — зрелость: extnav_ready и HUD READY

Двухступенчатый гейт (`_vins_ripe`):

- **Таймер**: `ripe_sec=30` sim-СЕКУНД потока от первой одометрии + пол
  счётчика `vins_min=300`. Счётчик-гейт (600 сообщ.) выброшен после разбора
  «моды 14.7 Гц»: freq-контроль feature_tracker после CPU-затыка на старте
  «выплачивает долг» кадрами, и 600 сообщений пролетали за 21-24 с (запас
  к физике масштаба ~21 с — нулевой). С таймером разброс READY — 1 с
  (было 20-62).
- **Детектор** (`ripeness.py`): residual «поза/скорость» тих 4 с +
  вертикальный ratio VINS/rel_alt в полосе [0.8,1.25] — пускает РАНЬШЕ
  таймера в хороший день (замер: зрелость на 8.9-10.6 с), таймер остаётся
  страховкой плохого. Пол детекторного пути — 8 с / 80 сообщ. res/rat видны
  в HUD мелкой строкой под баннером.

По зрелости очередь переписывает `POSXY=6` → `extnav_ready=True` → HUD: строка
яруса `> 2 LOITER` из `WAIT extnav 250/300 28/30s` становится `OK` (при высоте
> `loiter_alt`), баннер — зелёный `TIER 2 LOITER`. До этого VINS может быть идеально жив
(`ODO` зелёный) — карантин зрелости осознанный. Слепое пятно обоих путей:
рестарт VINS В ПОЛЁТЕ гейт не
видит — ловит свежесть (`vins_fresh`).

### Фаза 6 — SC вниз: ярус 2, штатный LOITER

Гейт тот же, что в LV=1 (единый источник правды — он же красит HUD-баннер):

```
extnav_ready   — фаза 5 состоялась
VINS свеж      — возраст одометрии < 2 с
в воздухе      — rel_alt (БАРО в LV=2) > loiter_alt (дефолт 0.5 м)
```

- Гейт открыт → `set_mode LOITER` с ре-ассертом; SC-вниз заранее — не
  ошибка: борт летит на лучшем доступном ярусе, LOITER возьмётся САМ при
  открытии гейта (реплеи: латч мгновенный, если READY уже был; 12-16 с,
  если щёлкнули раньше).
- FCU отказывает >5 с при открытом гейте → WARN `держу текущий ярус лесенки`
  — стек НЕ бросается до фактического латча (отличие от легаси).

### Жизнь в LOITER и выходы

- Стики = уставки СКОРОСТИ контроллера FCU; отпустил — держит точку.
- VINS/extnav протух (>3×2 с, гистерезис) → откат НА ЯРУС НИЖЕ (демпфер/
  VinsHold), не в голый ALT_HOLD.
- SF не-вверх → мгновенный MANUAL (ALT_HOLD, «стик = наклон»).
- FCU сам ушёл в LAND (EKF-failsafe) → уважаем, не ре-ассертим.

## Ниже 1.5 м (кампания low-rider)

`loiter_alt=0.5` (ручка `BS_LOITER_ALT`) — LOITER живёт ниже 1.5 м; демпфер
у земли — авторитет IPM-осей, гейт 0.08, масштабно-инвариантная полоса,
fine-мир: весь низковысотный слой — **`src/control/low-rider.md`**.
⚠️ Баро после посадки может залипнуть на 1.4-1.5 м — гейт «в воздухе» тогда
не закрывается сам, выход из LOITER на земле происходит по протуханию VINS;
залипание высоты также НЕ всегда блокирует детектор посадки FCU (дизарм
прошёл при баро 2.8 м — прогон 210723).

## Слои отказов LV=2 (сверху вниз; общие с LV=1 — в таблице соседа)

| Симптом | Причина | Фикс |
|---|---|---|
| PreArm: Check mag field (z diff:999>200), арм невозможен | origin ≠ реальная точка старта (WMM против магнитометра от дома SITL) | три гео-точки совпадают (Киев); страховка FREEFLY_NOARM 300 с |
| PreArm-чеки режут арм при «ARMING_CHECK 0» | в 4.8 параметр переименован в ARMING_SKIPCHK (инверсия) | `ARMING_SKIPCHK -1` в .parm + eeprom |
| LOITER мёртв весь полёт, EKF без позиции | нет origin (`BS_SET_ORIGIN=0`) или мост не издавал (aiding не стартовал на земле — LV4) | set_origin=1 (профиль LV=2 ставит сам); мост обязателен |
| Улёт на наборе после ЧУЖОГО прогона | eeprom увёл LV=0 (3/3) — но в LV=2 очередь его самовосстанавливает | штатно: очередь (а) |
| CH6/SC не даёт LOITER, «requires position» | EKF не дозрел / фьюжн голодает | ре-ассерт продолжается; диагностика dataflash — см. LV1_loiter.md |

Диагностика та же, что в LV1: dataflash `/root/sitl_state/logs/*.BIN`
(MSG → VISP↔XKF1 → XKF3-инновации → XKF4 SV/SP); тайминги фаз по bag —
`src/lab/phase_stats.py`.

## Шпаргалка пилота (SF-мастер)

1. `bash src/lab/freefly_lv.sh` (дефолты из `.env`), дождись в HUD/логе
   «EKF READY - TAKEOFF OK» (~8 с после старта ноды).
2. SF ВВЕРХ, SC можно сразу ВНИЗ (потолок LOITER — борт сам поднимется по
   лесенке). Арм руддером, взлетай.
3. HUD: init VINS на отрыве (`ODO` зеленеет) → баннер жёлтый `TIER 0 DAMPER` →
   `TIER 1 VINSHOLD` → зелёный `TIER 2 LOITER` через ~10-30 с (детектор/таймер);
   почему ждём — строка с `>` в блоке ярусов (`WAIT odom …`, `WAIT extnav …`,
   `WAIT ground` = ниже 0.5 м по баро).
   С этого момента ярус LOITER берётся сам; щёлкнул раньше — летишь на
   лучшем доступном (демпфер → VinsHold).
4. В LOITER стики = скорость. SF не-вверх = мгновенные сырые стики (MANUAL).
5. Посадка и дизарм руками (газ min + yaw ВЛЕВО 2-3 с). Дизарм завершает
   миссию; зависший дизарм страхуется (сервис → force → FREEFLY_STUCK).
