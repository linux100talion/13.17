# `docker/sim/rx.md` — КАРТА ПУЛЬТА: какой канал/орган за что отвечает

Сводка «пульт → канал → `/joy` → код → поведение борта» для RadioMaster TX12
(EdgeTX, режим **USB Joystick (HID)**). Источник правды — код, ссылки в каждой
строке; здесь собрано в одном месте, чтобы не искать по семи файлам.

## Что внутри (кратко)

- **Тракт** пульт → `joy_linux_node` → `/joy` → `JoyPilot` → `s.pilot_*` → план/стек →
  `rc/override` ch1..4 (и почему пульт идёт мимо FCU).
- **Таблица каналов** CH1…CH11+: орган TX12 → индекс в `/joy` → смысл → файл/ручка:
  - CH1–CH4 = стики (знаки `-1,+1,-1,-1`; почему pitch единственный прямой);
  - CH5 = `FLTMODE_CH` — не читаем (в симе 0, на борту ВКЛ = второй барьер);
  - CH6 = **SC** — потолок лесенки (вверх → ярус 0 демпфер, центр → 1 VinsHold,
    вниз → 2 LOITER) плюс легаси-семантика;
  - CH7 = **SF** — мастер сырых стиков;
  - CH8 = **не использовать** (квирк HID: дерётся с CH7 за `axes[6]`);
  - `buttons[0..23]` = CH9..CH32, из них **SA = `b1` (CH10)** — мягкая посадка
    (второе нажатие отменяет, на ярусе LOITER выключена);
  - остальные кнопки (SB, **SD**, …) — свободны.
- **Жесты** арм/дизарм с порогами и страховкой дизарма.
- **Эквиваленты с хоста**: `make sa-land` / `rth` / `smart-rth` / `pilot-done` и
  зеркала в реплей-сценариях (`sw`/`sf`/`land`).
- **Возврат домой** (`SMART_RTL` по следу): кнопка **SD** (`BS_RTH_JOY=b2`) и хост
  (`make rth` / `make smart-rth`) взводят один импульс; повторное нажатие отменяет.
- **Как измерить/менять**: `js_probe.py`, `joy_check.sh` и грабли — `weight −100` в
  миксе CH6, `default_trig_val:=true` (иначе тумблер, выставленный до старта ноды,
  читается центром), «мёртвая ось = дырка в микшере», кнопка «нажата» в покое.

## Тракт намерения пилота

Пульт входит в стек **МИМО FCU** — под активным `rc/override` полётник отдаёт в
`RC_CHANNELS` нашу же команду (петля, `ros_pilot.py` докстринг `RosPilot`):

```
TX12 (USB HID) → joy_linux_node → /joy → JoyPilot            (src/control/control_pkg/infrastructure/ros_pilot.py)
   → снапшот s.pilot_* (roll/pitch/throttle/yaw/switch/level/land)   (control_pkg/domain/state.py)
   → план freefly + стек стабилизаторов                              (src/mission/mission_pkg/plan/step.py)
   → /mavros/rc/override каналы 1..4                                 (control_pkg/infrastructure/mavros_actuator.py)
```

Нода — **единственный писатель** `rc/override`; каналы 5..18 уходят `NOCHANGE`.
Реплей (`BS_PILOT=replay`) подставляет `joy_replay.py` вместо `joy_linux_node` —
те же `/joy`-индексы, поэтому карта ниже общая для живого пульта и сценариев.

## Каналы

| CH | `/joy` | Орган TX12 | За что отвечает | Где в коде / ручка |
|---|---|---|---|---|
| CH1 | `axes[0]` | правый стик ↔ | **roll** (крен). Знак HID зеркальный → `-1` | `JOY_AXIS_ROLL`, `JOY_SIGNS_DEFAULT`, `BS_JOY_SIGNS` |
| CH2 | `axes[1]` | правый стик ↕ | **pitch** (тангаж). Единственный ПРЯМОЙ знак (`+1`): провод RC2 сам инвертирован | `JOY_AXIS_PITCH` |
| CH3 | `axes[2]` | левый стик ↕ | **throttle** (газ). Знак `-1`. В ALT_HOLD стик = вертикальная скорость, центр = держит высоту; вход в режим с отклонённым газом безопасен (`ThrottleLatch`) | `JOY_AXIS_THROTTLE`, `BS_ALT_DZ/SPAN/RATE_FULL` |
| CH4 | `axes[3]` | левый стик ↔ | **yaw** (курс). Знак `-1`; прямая передача стика в PWM — `BS_YAW_PILOT_GAIN` | `JOY_AXIS_YAW` |
| CH5 | `axes[4]` | тумблер FLTMODE (штатный) | **НЕ ЧИТАЕМ.** Это FCU-уровень safety: `FLTMODE_CH`. В симе `FLTMODE_CH 0` (радио не трогает режим, иначе перебивает `set_mode`), на боевом борту остаётся ВКЛ — второй барьер поверх Арбитра | `docker/sim/config/sitl-extra.parm`, `control_pkg/application/arbiter.py` |
| CH6 | `axes[5]` | **SC** (3-поз.) | **ПОТОЛОК ЛЕСЕНКИ** при `BS_SF_MASTER=1`: SC физически ВВЕРХ (HID −1) → ярус 0 «только демпфер»; ЦЕНТР (0) → ярус 1 «демпфер → VinsHold»; ВНИЗ (HID +1) → ярус 2 «… → штатный LOITER». Борт всегда на лучшей ДОСТУПНОЙ ступени ≤ потолка. Легаси (`BS_SF_MASTER=0`): вверх = наш стабилизатор, центр = чистый ALT_HOLD, вниз = MANUAL | `JOY_AXIS_SWITCH`, `joy_master()`, порог `0.5` (= «PWM > 1700») |
| CH7 | `axes[6]` | **SF** | **МАСТЕР СЫРЫХ СТИКОВ**: ВВЕРХ (> 0.5) = стабилизация разрешена; центр/вниз/оси нет = MANUAL-seize Арбитра (все четыре оси пилоту сырыми, миссия отстранена) при ЛЮБОМ SC. Требует микс SF→CH7 в EdgeTX | `JOY_AXIS_MASTER`, `BS_SF_MASTER` |
| CH8 | — | — | ⚠️ **НЕ ИСПОЛЬЗОВАТЬ.** Квирк HID TX12: в дескрипторе CH7 и CH8 — оба `Slider` → Linux кладёт их на один `ABS_THROTTLE`, joydev видит 7 осей, CH8 дерётся с CH7 за `axes[6]` (ось дрожит на частоте репорта) | `src/lab/joystick/js_probe.py` |
| CH9 | `buttons[0]` | — (свободна) | по коду EdgeTX classic кнопки `b0..b23` = CH9..CH32 (нажата при значении канала > 0). Дефолт ноды `BS_LAND_JOY=b0` | `joy_land()`, `parse_land_src()` |
| CH10 | `buttons[1]` | **SA** | **МЯГКАЯ ПОСАДКА** (`SoftLand`): при `rel_alt ≤ 5 м` и `|v| ≤ 1 м/с` — снижение 0.15 м/с, касание → газ в пол → дизарм. Второе нажатие до касания ОТМЕНЯЕТ посадку. ⚠️ На ярусе LOITER кнопка ОТКЛЮЧЕНА (`BS_LAND_IN_LOITER=0`) | `BS_LAND_JOY=b1` (`mission/baseline.txt`), `Freefly._land_press`, `BS_FF_LAND*` |
| CH11 | `buttons[2]` | **SD** | **ВОЗВРАТ ДОМОЙ** (шаг `Rth`): фронт нажатия = тот же импульс, что `make smart-rth` → борт уходит `SMART_RTL` (по крошкам пройденного пути), стек пуст, ведёт FCU. **Повторное нажатие ОТМЕНЯЕТ** возврат (борт обратно в freefly, ярус перепримет лесенка). В MANUAL (SF не вверх) — отказ с предупреждением. Режим кнопки — `BS_RTH_JOY_MODE` (`SMART_RTL` \| `RTL`) | `BS_RTH_JOY=b2` (`mission/baseline.txt`), `joy_button()` + `PressEdge`, `Rth` в `plan/step.py`. ПРОВЕРЕНА ПОЛЁТОМ lv2_joy_20260909_044105: два захода, по одному импульсу на нажатие |
| CH12+ | `buttons[3..23]` | **SB, …** — свободны | ни к чему не привязаны | — |

Индексы `buttons[i]` верить **только пробнику**: куда микшер положит орган —
его дело. На пульте проекта (замер 2026-08-30) SA пришла как `button[1]`, а не
`b0` дефолта → в профиле стоит `BS_LAND_JOY=b1`. Перенёс орган в микшере —
перемерь и поправь профиль.

## Жесты стиками (не каналы)

| Жест | Что делает | Пороги |
|---|---|---|
| газ вниз + руддер ВПРАВО | **арм** (штатный руддер-арм ArduPilot) | сценарий/анализатор: \|thr\|,\|yaw\| > 0.85 дольше 0.5 с |
| газ вниз + руддер ВЛЕВО, на земле | **дизарм**; если FCU не дизармится — через 8 с нода дизармит сервисом, через 30 с force (страховка `Freefly`) | PWM ≤ 1160 по обеим осям + `rel_alt ≤ 0.3 м` или gt |

## Эквиваленты с хоста (без пульта)

| Команда | Топик | Зеркало на пульте |
|---|---|---|
| `make sa-land` | `/mission/land` | кнопка SA |
| `make rth` | `/mission/rth` | — (нет) |
| `make smart-rth` | `/mission/smart_rth` | — (нет; кандидат SD) |
| `make pilot-done` | `/mission/pilot_done` | — (нет) |

В реплее (`joy_replay.py`, сценарии `src/lab/joystick/scenarios/`) органы —
ключи шагов: `{"sw": -1|0|1}` = CH6, `{"sf": 0|1}` = CH7, `{"land": 0|1}` =
кнопка SA (индекс `--land-btn`, синхронить с `BS_LAND_JOY`), `{"arm"}`/`{"disarm"}` —
жесты выше.

## Возврат домой: кнопка SD и хост — один и тот же шаг

Кнопка SD и топики `/mission/rth` | `/mission/smart_rth` (`make rth` /
`make smart-rth`) взводят ОДИН импульс `s.pilot_rth`; какой режим FCU слать,
решает источник: топик — сам собой, кнопка — ключом `BS_RTH_JOY_MODE`
(дефолт `SMART_RTL`). Дальше всё общее: `Freefly` прыгает на шаг `rth`, тот
шлёт режим до латча, а повторный импульс (ЛЮБОЙ из двух источников) отменяет
возврат. Разница только в удобстве: кнопка — в воздухе, одной рукой.

**Что сделать на пульте (один раз):** в микшере EdgeTX назначить SD на первый
свободный канал ПОСЛЕ осей — **CH11** (`weight 100`, чтобы «нажато» давало
значение > 0), проверить пробником, что дёргается `button[2]`, и, если индекс
другой, поправить `BS_RTH_JOY` в `src/control/profiles/mission/baseline.txt`.
При старте нода печатает, что слушает: `кнопка ВОЗВРАТА пульта: /joy b2 → SMART_RTL`.

- Кнопки нет / индекс не тот → `BS_RTH_JOY=` (пусто) = выключено, возврат
  остаётся только с хоста.
- Реплей: шаг сценария `{"rth": 1}` / `{"rth": 0}` (уровень — фронт нода ловит
  сама), индекс кнопки реплею отдаёт `bootstrap_arch2.sh` из того же `BS_RTH_JOY`.
- ⚠️ Зажатая на старте ноды кнопка нажатием НЕ считается (`PressEdge`): фронт
  ловится только после того, как её отпустили.
- Возврат может отмениться САМ (`RTH_GUARD`, `BS_RTH_GUARD=1`): мост VINS→EKF закрыт
  или гейт здоровья объявил VINS больным дольше секунды — борт возвращается пилоту на
  демпфере, а не летит домой по цифрам EKF, которые больше нечем подтягивать.
  Вся цепочка гейтов — `src/control/gates.md`.

## Как измерить и как менять

```bash
python3 src/lab/joystick/js_probe.py            # хост, /dev/input/js0, 30 с:
                                                # печатает КАЖДОЕ изменение axis[i]/button[i]
docker exec -it p1317_nav bash /lab/joy_check.sh # стики ГЛАЗАМИ НОДЫ (то же ядро joy_sticks):
                                                # PWM всех осей + MANUAL/AUTO + SF
```
После прогона то же видно в ленте: `src/lab/joystick/analyze.sh` → `report.txt`
(«JOY: кнопка b1 нажата», щелчки CH6, жесты арм/дизарм).

Грабли, оплаченные полётами:

- **Направление тумблера правится микшером, не кодом.** Сырой SC в EdgeTX даёт
  вверх = −100, HID зеркалит канал → в миксе CH6 нужен `weight −100` **числом**
  (не GVAR). Монитор каналов пульта показывает канал ДО HID-зеркала — сверять
  по `joy_check`.
- **Начальное состояние осей.** `joy_linux_node` по умолчанию игнорирует
  `JS_EVENT_INIT`: выставленный ДО старта ноды тумблер публикуется как `0.00`
  до первого движения (полёт 2026-08-17: CH6 вверх весь полёт читался центром).
  Лечится `-p default_trig_val:=true` — уже стоит в `bootstrap_arch2.sh` и
  `joy_check.sh`.
- **Мёртвая ось в bag = дырка в микшере**, а не бага ноды: EdgeTX шлёт 0 по
  каналу без микса. Знак оси не считается выверенным, пока ось не отработала
  в воздухе.
- **Кнопка «нажата» в отпущенном состоянии** — поставить в миксе `Weight −100`.
- Знаки осей — `JOY_SIGNS_DEFAULT` (выверены живыми полётами), переопределение
  `BS_JOY_SIGNS="r,p,t,y"`.
